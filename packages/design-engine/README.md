# @planmo/design-engine

The PlanMo frontend design engine: DTCG design tokens, eight visual styles, accessibility and motion rules, and the shadcn source adapter.

This package is part of the PlanMo workspace. The user-facing entry point is the
[`planmo`](https://www.npmjs.com/package/planmo) CLI.
