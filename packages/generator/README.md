# @planmo/generator

The PlanMo planning compiler and artifact generator: canonical IR, renderers, the generation manifest and the synth preview.

This package is part of the PlanMo workspace. The user-facing entry point is the
[`planmo`](https://www.npmjs.com/package/planmo) CLI.
