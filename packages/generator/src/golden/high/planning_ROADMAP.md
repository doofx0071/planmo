# Detailed Roadmap

## Phase 00 — Product & research foundation

Lock product boundaries, naming, licensing criteria, and non-goals..

## Phase 01 — Repository & engineering foundation

Create monorepo toolchain, strict types, lint/format/test, CI, boundaries..

## Phase 02 — Canonical project model & schemas

Schema-version every persisted PlanMo document and add migration tests..

## Phase 03 — CLI foundation

Implement init, safe filesystem writer, dry-run/diff, ownership rules, status..

## Phase 04 — Pack & profile system

Implement declarative packs, deterministic resolution, lockfile, profiles..

## Phase 05 — Planning compiler & artifact generator

Generate plan documents with an ownership manifest and reproducible regeneration..

## Phase 06 — Agent bridge

Implement generic and per-agent adapters with a structured AI proposal contract..

## Phase 07 — Frontend design engine

Implement design profiles, design tokens, eight styles, frontend docs..

## Phase 08 — Workflow/session engine

Implement phases, handoffs, work packets, gates, planmo next..

## Phase 09 — Trace, validate, doctor & drift

Implement trace graph, validation, drift detection, doctor command..

## Phase 10 — Existing repository adoption

Support adopting an existing repository incrementally..

## Phase 11 — Ecosystem & integrations

Packs registry, templates, agent ecosystem integrations..

## Phase 12 — Hardening, pilot & v1

Hardening, security review, pilot, and v1 release..
