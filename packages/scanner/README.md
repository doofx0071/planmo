# @planmo/scanner

The PlanMo repository-adoption engine: safe scanning of untrusted repositories,
stack/test/CI detection with evidence, prompt-injection isolation, dry-run adopt
reports, repository context maps and lexical context indexing.

This package is part of the v1 runtime closure of the
[`planmo`](https://www.npmjs.com/package/planmo) CLI and is published so that
`npm install planmo` resolves. You normally do not depend on it directly.
