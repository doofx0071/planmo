# @planmo/schema

The canonical PlanMo project model: versioned, Zod-validated schemas for project
config, state, pack metadata, lockfile, manifest, requirements, design profiles,
trace graphs, handoffs and work packets, plus their migration rules.

This package is part of the v1 runtime closure of the
[`planmo`](https://www.npmjs.com/package/planmo) CLI and is published so that
`npm install planmo` resolves. You normally do not depend on it directly.
