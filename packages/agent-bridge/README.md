# @planmo/agent-bridge

The PlanMo agent bridge: capability declarations, proposal validation, token-budgeted context bundles and memory providers.

This package is part of the PlanMo workspace. The user-facing entry point is the
[`planmo`](https://www.npmjs.com/package/planmo) CLI.
