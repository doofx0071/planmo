# @planmo/packs

The PlanMo declarative pack system: pack loading, deterministic resolution with surfaced conflicts, lockfiles, planning-depth profiles and the standards/policy selection engine.

This package is part of the PlanMo workspace. The user-facing entry point is the
[`planmo`](https://www.npmjs.com/package/planmo) CLI.
