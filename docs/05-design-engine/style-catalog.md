# Initial Style Catalog

## Minimal
Whitespace, hierarchy, limited decoration, restrained motion.

## Editorial
Typography-first, deliberate rhythm, strong reading hierarchy.

## Neobrutalism
Strong borders, assertive geometry, high-contrast surfaces, intentional weight.

## Soft Product
Rounded geometry, breathable spacing, approachable controls.

## Dense Dashboard
Compact, scanable, information-dense, restrained ornament.

## Developer Tool
Functional, precise, keyboard-centric, code/mono-aware when appropriate.

## Luxury
Premium typography/spacing/material restraint; avoid stereotyped gold-gradient treatment.

## Playful
Expressive shape/motion/color while preserving hierarchy/accessibility.

Every style pack has `anti-patterns.md` to reduce generic AI styling.
