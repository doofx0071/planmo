# Frontend Design Engine

PlanMo treats frontend architecture and visual design as structured planning input.

Layers:

```text
Framework
 -> Component foundation
 -> Component sources
 -> Visual style
 -> Design tokens
 -> Typography/icons
 -> Density
 -> Motion
 -> Accessibility
 -> Responsive rules
```

Examples:
- `shadcn` = component/source ecosystem, not a visual style.
- `Neobrutalism` = visual style.
- Base UI/Radix/React Aria = component foundations.
- animation/component registries = optional sources.
