# Change Management

Future command concept:

`planmo change "Add multi-tenancy"`

Creates:
```text
planning/changes/CHG-004-multitenancy/
├── proposal.md
├── impact.md
├── requirements.md
├── tasks.md
└── decision.md
```

Impact analysis covers requirements, architecture, security, design, roadmap, tasks, and tests.

Applying a change updates canonical state through validated transformations, not blind text replacement.
