# Exit Code Contract

Proposed:
- `0` success
- `1` general failure
- `2` invalid usage
- `3` schema/config invalid
- `4` validation/doctor error findings
- `5` filesystem safety refusal
- `6` pack resolution failure
- `7` blocked workflow/human gate
- `8` unsupported compatibility
- `9` external integration failure

Stabilize near v1.
