# Interactive Wizard

Use progressive disclosure.

Example:

```text
What are you planning?
> New project
  Existing project
  Feature/change
  Migration
  Refactor
  Security hardening

Planning depth?
> Recommended
  Lean
  Standard
  Production
  High Assurance
  Custom

Visual direction?
> Minimal
  Editorial
  Neobrutalism
  Soft Product
  Dense Dashboard
  Developer Tool
  Luxury
  Playful
  None / backend-only

Primary AI agent?
> Generic
  OpenCode
  Codex
  Claude Code
```

Questions are conditional. Wizard output is structured configuration, not freeform final docs.
