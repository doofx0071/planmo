# Context + Standards + Quality Integration

The three systems should reinforce each other.

1. Task Graph determines the active task.
2. Standards Engine selects applicable rules.
3. Context Engine retrieves relevant repository/memory evidence.
4. Execution Packet combines task + standards + context + risks + tests.
5. Agent implements.
6. Quality Engine validates architecture/maintainability.
7. Handoff records results.
8. Memory lifecycle stores only durable deltas.
9. Trace engine links requirement → task → evidence → release.
