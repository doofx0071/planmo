1. Hybrid CLI + agent commands/skills.
2. Canonical semantics independent from invocation syntax.
3. Extensible packs/profiles, declarative in v1.
4. DTCG tokens prevent Tailwind/shadcn lock-in.
5. shadcn registry is an adapter/source ecosystem.
6. Existing-project adoption is core.
7. Persistent phase/session state + handoffs.
8. validate/doctor/trace are first-class.
