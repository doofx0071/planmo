# Planning Depth Profiles

## Lean
AGENTS, brief, plan, tasks, essential decisions.

## Standard
Adds requirements, architecture, roadmap, ADRs, testing, Git workflow.

## Production
Adds operations, monitoring, backup/DR, security baseline, release strategy, risk register.

## High Assurance
Adds detailed threat model, privacy/compliance investigation, abuse cases, security test matrix, stronger traceability, human gates, incident response, evidence requirements.

Profiles are adaptive starting points, not fixed file counts.
