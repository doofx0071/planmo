# ADR-0015 — First-class Change Packages and Requirement Deltas

**Status:** Accepted (CHG-001; originally proposed as pack ADR-0010, renumbered to avoid collision with existing ADR-0010 cli-routing)

Substantial changes after initial planning are represented as change packages containing explicit ADDED/MODIFIED/REMOVED requirement deltas, impacts, risks, tasks, and tests.

Accepted changes are merged into canonical planning state and archived with provenance.

See `docs/15-change-governance/change-engine.md` (workflow: `planmo change new|apply|archive`).
